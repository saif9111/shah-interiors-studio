# Shah Interiors Studio

Build a **premium, modern, responsive multipage static website** for my interior design business:



# SHAH INTERIOR



Tagline: **Thoughtful interiors. Timeless spaces.**



The goal is to create a visually impressive interior-design portfolio website that feels like a **2026 luxury architecture/interior-design studio website**, while keeping the implementation simple and lightweight.



## IMPORTANT — KEEP THE BUILD LIGHT



This is being built on Lovable's free plan.



* Keep the codebase simple and efficient.

* Avoid unnecessary libraries and complex functionality.

* Do not build a backend, database, authentication, CMS, dashboard, or payment system.

* Use static/local data for projects and services.

* Use reusable React components.

* Do not over-engineer the website.

* Prioritize the visual design and core user experience.

* Make all content easy to replace later.



## TECH STACK



Use:



* React

* Tailwind CSS

* Simple reusable components

* Responsive CSS

* Lightweight animations only where useful



No unnecessary dependencies.



---



# DESIGN STYLE



Create a **high-end interior design studio aesthetic**.



Visual direction:



**Modern + Minimal + Warm + Luxury + Architectural**



Use:



* Large editorial typography

* Large interior photographs

* Generous whitespace

* Clean layouts

* Asymmetric editorial grids

* Subtle rounded corners

* Elegant hover effects

* Smooth scrolling

* Simple fade/reveal animations

* Strong visual hierarchy



Avoid:



* Generic business-template appearance

* Bright/neon colors

* Excessive gradients

* Excessive glassmorphism

* Overly complicated animations

* Cartoon illustrations

* Tech-startup styling



The website should look expensive without being visually cluttered.
